1. En une phrase

DiagOps est un assistant de maintenance industrielle. En M5, on ne crée pas une IA plus intelligente : on apprend à déployer, surveiller et réparer la version déjà faite en M4.

Ce qu’on protège Une version saine appelée diagops-m4-reference-r1. On peut toujours y revenir (rollback).
Ce qu’on prouve Si ça casse, on le détecte (métriques), on décide, on restaure, et on écrit l’histoire dans la timeline.

Objectifs chrono : détection < 2 min · décision < 5 min · restauration < 10 min. Guide détaillé : game_day/JOUR_J.md

5. La timeline — c’est quoi ? Comment la modifier ?

La timeline n’est pas un programme qui tourne. C’est un fichier texte Markdown : ton carnet de bord pendant l’incident. Tu l’édites à la main (Cursor / VS Code), une ligne par événement.

Fichier

work/M5/game_day/timeline.md

Structure d’une ligne

Colonne Que mettre Exemple
Horodatage UTC Heure réelle en UTC 2026-09-07T14:02:15Z
Observation Ce que tu as vu ready passe à 503
Signal Preuve système diagops_index_valid=0
Décision Ce que tu choisis rollback vers release saine
Responsable Qui agit toi / Incident commander
Preuve Où c’est visible curl, Prometheus, capture

Comment modifier (pas à pas)

  1. 1 Ouvre work/M5/game_day/timeline.md dans Cursor.
  2. 2 Dans un terminal, prends l’heure UTC : 
    date -u +"%Y-%m-%dT%H:%M:%SZ"
  3. 3 Ajoute une nouvelle ligne dans le tableau (ne supprime pas les anciennes) : 
| 2026-09-07T14:02:15Z | ready 503 | index_valid=0 | Je clear la faute | Moi | curl + Prometheus |
  1. 4 Enregistre le fichier (Cmd+S). C’est tout — pas de “lancer la timeline”.
Les lignes déjà présentes = exercice d’entraînement du 7 sept. Le jour J, tu peux les garder comme exemple et ajouter les nouvelles lignes de l’incident réel en dessous (ou remplacer la section si le formateur demande une timeline “propre”).

Obtenir l’heure UTC facilement

# macOS / Linux
date -u +"%Y-%m-%dT%H:%M:%SZ"

# pendant un test
curl -s -w "\n%{http_code}\n" http://127.0.0.1:8000/health/ready
# → note l’heure + le code HTTP dans timeline.md

Ligne droite à 1 = système sain maintenant (ou tu regardes trop tard). Pour voir un creux : ouvre le graph avant d’injecter, plage Last 5 minutes, requête diagops_index_valid.
