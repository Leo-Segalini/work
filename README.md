# Espace de travail apprenant

Ce dossier est volontairement vide dans le dépôt pédagogique. Chaque apprenant
y initialise et versionne sa production sur la branche `main` de son dépôt
privé indépendant :

```bash
python3 tools/init_module.py M2
```

Le dépôt pédagogique ne publie aucun contenu dans `work/MN/`. Les mises à jour
reçues depuis `upstream/main` peuvent donc être fusionnées dans la branche
`main` privée sans remplacer les productions.
